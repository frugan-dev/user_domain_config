# AGENTS.md

Instructions for AI agents working on this repository. Everything a human
contributor needs is in [CONTRIBUTING](.github/CONTRIBUTING.md): read it, this
file does not repeat it.

## Hard rules

- **The domain is validated before it reaches a path.** It comes from the
  login form before authentication and is passed to `load_from_file()`:
  keep `domain()` the only way to it, and keep the path traversal checks of
  `tests/smoke.sh` passing.
- **PHP 7.1 syntax and the Roundcube 1.5 API**, as declared in
  `composer.json`. Raising either is a breaking change: say so in the commit
  footer and update the README requirements.
- **No runtime dependency** besides the plugin installer.
- **Never read `.env`.** Only `.env.dist` is tracked.
- There is no `CHANGELOG.md`: the release notes are generated by
  semantic-release from the commit log.

## Commands

Everything runs in Docker. If you cannot run it, say which commands have to be
run and what output to look for.

```bash
docker compose up -d --wait
tests/smoke.sh
docker compose run --rm composer install
docker compose run --rm composer lint
```

## Conventions

- Code, comments and commit messages in English. Comments explain why, not
  what.
- Conventional Commits, plus the `deps` type: the type decides the release
  (see CONTRIBUTING). Body lines up to 150 characters.
- Roundcube's naming: the class and its methods are snake_case, like the
  plugin API they implement.
- A change in behaviour comes with a check in `tests/smoke.sh` and, if it is
  visible to administrators, a line in the README.

## Private notes

`agents/` is gitignored. If your checkout has it, it holds the maintainer's
notes: read what is relevant to the task, never reference it from versioned
files.
